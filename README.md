# 💡 Idea Lab

> **Your personal thought dumpyard — capture fast, organize smart.**

Idea Lab is a mobile application that lets you dump your random thoughts and ideas instantly, then automatically categorizes and organizes them so you can find them whenever inspiration strikes again.

---

## ✨ Features

### Core (POC)
- 📝 **Quick Capture** — Type a thought and save it in seconds
- 🗂️ **Category Selection** — Manually assign a category while saving
- 📊 **User Dashboard** — View all your ideas grouped by category

### Phase 2
- ✏️ **Full CRUD** — Create, update, and delete both ideas and categories
- 🔀 **Move Ideas** — Drag and drop ideas between categories
- 🏷️ **Rename Categories** — Keep your organization clean and up to date

### Phase 3 (Smart)
- 🤖 **Auto-Categorization** — AI detects the right category based on a ranking metric
- 🆕 **Dynamic Category Creation** — If no matching category exists, a new one is auto-generated from context
- 🔍 **Hassle-free Discovery** — Find ideas without remembering where you saved them

## 📱 App Flow

```
Home Screen
  └── [+] New Idea
        ├── Type your thought
        ├── Select or auto-detect category
        └── Save

Dashboard
  └── Categories
        ├── Category A
        │     ├── Idea 1
        │     └── Idea 2
        └── Category B
              └── Idea 3
```
